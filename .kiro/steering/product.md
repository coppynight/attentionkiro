# Product Overview

**人生就是一个项目，你花费的时间就是在向人生的git提交记录，你还可以给你的美好时刻打上tag。**

Timelog（时间日志）是一个充满诗意的iOS时间管理应用，将人生比作一个代码项目，让用户以程序员的视角审视和优化自己的时间使用。

## 产品理念
- **时间即代码**: 每分钟的时间使用都是一次向人生项目的commit
- **美好时刻标记**: 为重要时刻打tag，就像标记重要的代码版本
- **人生贡献图**: GitHub风格的热力图展示每天的时间投入
- **智能代码审查**: AI分析时间使用模式，提供人生优化建议

## Core Features
- **🔥 人生贡献图**: GitHub-style heatmap showing daily "life contributions"
- **🏷️ 时间标签系统**: Tag time blocks like git commits with meaningful labels
- **🧠 智能代码审查**: AI-powered analysis of time usage patterns and habits
- **⚙️ 项目设置管理**: Customize time tracking parameters like project configuration
- **✨ 美好时刻标记**: Mark special moments with beautiful tags and descriptions
- **🌿 人生分支管理**: Organize different life modes like code branches

## Target Platform
- iOS mobile application
- Supports iPhone and iPad orientations
- Minimum iOS deployment target as configured in project settings

## Key Concepts
- **Time Commit**: Each time period is a commit to your life project
- **Life Heatmap**: Visual representation of daily activity like GitHub contributions
- **Time Tags**: Meaningful labels for time blocks, like git tags for releases
- **Beautiful Moments**: Special time periods marked with extra significance
- **Life Branches**: Different life modes (work, study, leisure) managed separately
- **Version Releases**: Major life milestones celebrated like software releases
